# 在线学习：远程课程与虚拟实验

- 远程教育
- 虚拟实验室
- 录播课程、直播讨论和在线作业

在线学习提供了灵活的时间和资源选择，但需要主动规划和反馈机制，避免只收藏课程或持续播放视频却没有练习。

## 选择课程时检查

1. 学习目标和先修知识是否明确？
2. 是否包含作业、项目、测验或其他反馈？
3. 课程内容、工具版本和参考资料是否更新？
4. 是否能获得讲义、代码和可复现的实验环境？
5. 完成课程后能展示什么成果？

## 推荐学习节奏

- 每次学习前确定一个问题。
- 将观看内容切分为短单元，每段后主动回忆。
- 尽快完成练习，不要等课程全部结束才动手。
- 在讨论区提出具体问题，并记录解决方案。
- 每周复盘成果、错误和下一步行动。

在线课程只是输入渠道，最终应以独立解释、练习结果和实际项目验证掌握程度。
