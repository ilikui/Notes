# 数列极限的定义（ε-N 定义）

设数列 \(\{x_n\}\) 与常数 \(a\)。如果对任意给定的 \(\varepsilon>0\)，都存在正整数 \(N\)，使得当 \(n>N\) 时有

\[
|x_n-a|<\varepsilon,
\]

则称数列 \(\{x_n\}\) 收敛于 \(a\)，记作

\[
\lim_{n\to\infty}x_n=a.
\]

直观上，无论给定多小的误差范围 \(\varepsilon\)，只要项数足够大，数列后面的所有项都会落在 \(a\) 的 \(\varepsilon\) 邻域内。

## 逻辑结构

\`\`\`mermaid
flowchart TD
    A[任意给定 ε > 0] --> B[找到一个 N]
    B --> C[对所有 n > N]
    C --> D[都有 |x_n - a| < ε]
    D --> E[数列收敛到 a]
\`\`\`

## 示例：\(x_n=1/n\) 收敛到 0

需要证明：任给 \(\varepsilon>0\)，找到 \(N\) 使 \(n>N\) 时 \(1/n<\varepsilon\)。取一个满足 \(N>1/\varepsilon\) 的正整数即可；于是对所有 \(n>N\)，有

\[
|x_n-0|=\frac1n<\varepsilon.
\]

所以 \(\lim_{n\to\infty}1/n=0\)。

## 证明时的注意点

- \(\varepsilon\) 是任意给定的正数，不是固定的小数。
- 找到 \(N\) 后，必须说明所有 \(n>N\) 都满足不等式。
- \(N\) 可以依赖 \(\varepsilon\)，但不能依赖后续任意选取的 \(n\)。
- 极限唯一性意味着同一个数列不能收敛到两个不同的实数。
