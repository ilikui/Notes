# Vim 文本编辑器

- 中文学习资料：[Vim 入门与使用](https://gitlab.com/wsdjeg/vim-galore-zh_cn)

Vim 是面向键盘操作的文本编辑器。学习重点不是记住全部命令，而是掌握移动、编辑、搜索、替换、窗口和撤销等高频动作。

## 常用模式

- 普通模式：移动光标、选择文本、执行编辑命令。
- 插入模式：输入文本。
- 命令行模式：执行保存、退出、查找替换等命令。
- 可视模式：选择文本区域后批量操作。

## 入门练习

1. 打开文件，练习保存和退出。
2. 使用 h/j/k/l 或方向键移动，练习单词、行首/行尾和屏幕移动。
3. 练习删除、复制、粘贴、撤销与重做。
4. 使用 / 搜索、n/N 跳转，练习替换。
5. 分屏打开多个文件，比较差异并快速切换。
6. 熟悉后再配置插件和快捷键，避免过早复杂化。

先掌握不依赖插件的基本编辑能力；配置文件应纳入版本控制并做好备份。遇到命令不熟悉时使用内置帮助，而不是记住来源不明的配置片段。
