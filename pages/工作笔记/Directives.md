# 汇编伪指令与汇编器指令

伪指令用于指导汇编器组织代码、声明数据、定义段或过程等，通常不对应一条 CPU 实际执行的机器指令。语法随汇编器与目标架构变化，SEGMENT、PROC 等示例主要对应部分 x86 汇编器语境。

## 常见类别

- 数据定义：DB、DW、DD 等（名称与含义依汇编器语法）。
- 段定义：SEGMENT、ENDS 或其他段声明方式。
- 过程定义：PROC、ENDP 等过程边界声明。
- 符号与常量：标签、常量定义、导入/导出声明。
- 条件汇编：根据宏、平台或构建选项选择代码。

## 与机器指令的区别

伪指令影响代码布局、符号、段属性或生成过程；机器指令则会被转换为目标处理器可执行的操作码。

## 阅读或修改时确认

1. 汇编器名称、版本与目标指令集。
2. 段属性、对齐、符号可见性和数据宽度。
3. 伪指令对生成代码、内存布局和链接的影响。
4. 是否存在宏展开、条件汇编或特定 ABI 约定。

不要把某一汇编器的伪指令语法直接套用到其他工具链。
