# 考研高等数学｜公式速查与题型索引

> 作为复习入口，不代替章节推导。考试范围请以目标院校和当年数学一/二/三考试大纲为准。

## 一、极限

- 两个重要极限：\(\lim_{x\to0}\sin x/x=1\)，\(\lim_{x\to\infty}(1+1/x)^x=e\)。
- 等价无穷小：\(\sin x\sim x\)，\(\tan x\sim x\)，\(1-\cos x\sim x^2/2\)，\(\ln(1+x)\sim x\)，\(e^x-1\sim x\)。
- 洛必达：仅用于符合条件的 (0/0\)、\(\infty/\infty\) 型。

## 二、导数

- 乘积：\((uv)'=u'v+uv'\)。
- 商：\((u/v)'=(u'v-uv')/v^2\)。
- 复合：\((f(g(x)))'=f'(g(x))g'(x)\)。
- 隐函数：若 (F(x,y)=0\)，且 (F_y\ne0\)，则 (y'=-F_x/F_y\)。
- 参数：\(dy/dx=(dy/dt)/(dx/dt)\)。

## 三、积分

- 分部：\(\int u,dv=uv-\int v,du\)。
- 微积分基本定理：\(\int_a^b f(x)dx=F(b)-F(a)\)。
- 变上限：\(\frac d{dx}\int_{u(x)}^{v(x)}f(t)dt=f(v)v'-f(u)u'\)。
- 极坐标面积元：\(dA=rdrd\theta\)；柱坐标体积元：\(dV=rdrd\theta dz\)。

## 四、多元微分

- 梯度：\(\nabla f=(f_x,f_y,f_z)\)。
- 方向导数：\(D_uf=\nabla f\cdot u\)（(u\) 为单位向量）。
- 隐函数：\(dy/dx=-F_x/F_y\)。
- 二元极值判别：\(D=f_{xx}f_{yy}-f_{xy}^2\)。

## 五、微分方程

- 一阶线性：\(y'+P(x)y=Q(x)\)，积分因子 \(\mu=e^{\int Pdx}\)。
- 可分离变量：\(dy/h(y)=g(x)dx\)，需检查除法可能丢失的常值解。
- 二阶常系数：特征方程根对应指数解；重根乘 (x\)，复根转为指数乘正弦余弦。

## 六、级数

- 必要条件：\(a_n\to0\)。
- (p\) 级数：\(\sum1/n^p\) 在 (p>1\) 收敛。
- 比值/根值：极限小于1收敛，大于1发散，等于1失效。
- 幂级数端点必须分别判断。

## 七、题型索引

| 题型 | 推荐切入点 | 必查条件 |
|---|---|---|
| 参数极限 | 左右极限、主导项 | 极限是否存在 |
| 分段连续 | 左极限、右极限、函数值 | 三者相等 |
| 导数定义 | 差商化简 | 不可提前令增量为0 |
| 中值定理 | 构造辅助函数 | 连续与可导条件 |
| 单调极值 | 一阶导数符号表 | 驻点不必是极值 |
| 定积分面积 | 画区域、上减下 | 交点与分段 |
| 反常积分 | 极限定义、比较 | 每个奇点/无穷端分别判断 |
| 多元极值 | 驻点、Hessian判别 | 判别式为0时需另法 |
| 重积分 | 画区域、换坐标 | 雅可比 |
| 曲线曲面积分 | 参数化/积分公式 | 方向与法向 |
| 级数判敛 | 通项、比较、比值 | 比值极限为1不确定 |

## 八、考前检查

- 能不看笔记写出常用公式，并说明每个公式的适用条件。
- 能独立完成每章基础题、变式题和跨章节综合题。
- 错题记录“错因”而不只是正确答案。
- 考试范围按数学一/二/三及目标年份核对；本索引不自行判定必考范围。
