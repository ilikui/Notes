# 处理器寄存器入门

寄存器是 CPU 内部用于保存操作数、地址、状态和控制信息的高速存储单元。寄存器名称和宽度随架构、指令集和执行模式变化；EAX、EIP、ESP 等属于 x86 32 位命名体系，不适用于所有处理器。

## 常见 x86 32 位寄存器类别

| 类别 | 示例 | 典型用途 |
|---|---|---|
| 通用寄存器 | EAX、EBX、ECX、EDX | 运算、临时值和参数（具体依 ABI） |
| 指令指针 | EIP | 下一条待执行指令的位置 |
| 栈指针 | ESP | 当前栈顶位置 |
| 基址指针 | EBP | 某些调用约定下用于访问栈帧 |
| 索引寄存器 | ESI、EDI | 字符串/内存操作或通用地址计算 |
| 段寄存器 | CS、DS、ES、SS | x86 分段机制相关的选择子/状态 |

## 调试用途

- PC/IP 类寄存器：确认程序卡在哪里或异常返回到了哪里。
- SP 类寄存器：检查栈是否越界、是否与调用约定一致。
- 状态寄存器：查看条件标志、中断屏蔽和处理器模式。
- 外设寄存器：验证时钟、复位、引脚复用、中断和通信控制器配置。

```mermaid
flowchart LR
    A[异常/故障] --> B[读取 PC/IP]
    B --> C[查看调用栈与 SP]
    C --> D[检查状态寄存器]
    D --> E[定位源代码/汇编]
    E --> F[验证内存与外设状态]
```

分析 MCU 时必须使用目标芯片参考手册、核心架构手册和调试器文档确认寄存器含义。
