# 笔记软件

> 笔记软件的价值在于帮助记录、组织、检索、连接和复用知识。选择工具时应先确定工作流与数据所有权，再比较界面功能；不要因为功能很多而让同一条知识分散在多个系统中。

## 1. 原有软件与入口

| 软件 | 官方/产品入口 | 选择前需要确认 |
|---|---|---|
| 印象笔记 | [yinxiang.com](https://www.yinxiang.com/) | 导出格式、同步策略、账号与数据迁移 |
| 有道云笔记 | [note.youdao.com](https://note.youdao.com/) | 导出能力、附件保存与平台支持 |
| 为知笔记 | [wiz.cn](https://www.wiz.cn/zh-cn) | 本地/云端使用方式、备份与迁移 |
| MyBase | [wjjsoft.com](https://www.wjjsoft.com/mybase.html) | 数据库文件、跨设备访问和长期可读性 |
| Capacities | [capacities.io](https://capacities.io/) | 对象化组织方式、导出与离线能力 |
| Heptabase | [heptabase.com](https://heptabase.com/download) | 白板工作流、卡片组织和数据导出 |

> 软件功能、定价和服务政策会变化。上表是原有资源入口与评估维度，不代表当前版本的完整功能对比；选型前请核对官方说明。

## 2. 按工作流选择

| 主要需求 | 重点能力 |
|---|---|
| 快速捕捉灵感 | 低摩擦输入、移动端入口、搜索 |
| 长期知识库 | 双向链接、稳定页面标识、批量导出 |
| 阅读与文献 | PDF/EPUB 标注、来源信息、引用管理 |
| 卡片与复习 | 问题卡、主动回忆、间隔复习、复习记录导出 |
| 视觉思考 | 白板、卡片移动、图像和关系图 |
| 工程知识 | Markdown、代码块、版本控制、可复现示例 |
| 多设备工作 | 离线能力、冲突处理、同步与备份 |

## 3. 评估工具的检查清单

- [ ] 能否完整导出正文、附件、链接和元数据？
- [ ] 导出的文件是否能在不依赖该软件的情况下继续读取？
- [ ] 是否支持离线使用以及可理解的同步冲突处理？
- [ ] 搜索、标签、链接和批量编辑是否满足实际规模？
- [ ] 隐私政策、权限、账号恢复和服务连续性是否可接受？
- [ ] 是否容易将内容迁移到另一个系统？
- [ ] 是否存在重复存储、重复提醒和维护成本？

## 4. 建议的知识工作流

```mermaid
flowchart LR
    A[收集] --> B[阅读与标注]
    B --> C[提炼主题笔记]
    C --> D[链接与索引]
    D --> E[复习或实践]
    E --> F[写作与输出]
    F --> G[复盘和更新]
```

尽量明确一个主存储位置。其他工具可以承担捕捉、阅读、复习或展示等角色，但需要清楚数据如何回到主知识库。
