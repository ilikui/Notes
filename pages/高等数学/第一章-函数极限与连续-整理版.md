# 第一章｜函数、极限与连续（整理版）

> 本页是系统化学习稿；原始 Flomo 归档保持不变。公式使用前必须检查定义域、极限存在条件与定理前提。

## 1. 函数基础

函数是从定义域 (D) 到数集的对应：每个 (x\in D) 对应唯一的 (y=f(x))。重点检查定义域、值域、奇偶性、周期性、单调性、有界性、反函数和复合函数。

- 分母：不为 0；偶次根式：被开方数非负；对数：真数大于 0。
- 奇偶性先检查定义域关于原点对称，再检验 (f(-x)=\pm f(x))。
- 反函数要求一一对应；若原函数不单调，通常先限制定义域。
- 复合函数 (g(f(x))) 要求 (x\in D_f) 且 (f(x)\in D_g)。

## 2. 极限的定义与性质

数列极限：对任意 (\varepsilon>0)，存在正整数 (N)，使 (n>N\Rightarrow |x_n-a|<\varepsilon)。

函数极限：对任意 (\varepsilon>0)，存在 (\delta>0)，使 (0<|x-x_0|<\delta\Rightarrow |f(x)-A|<\varepsilon)。

核心逻辑：先给任意误差，再找到控制范围；函数极限定义中的 (0<|x-x_0|) 表示不要求函数在 (x_0) 处有定义，也不要求 (f(x_0)=A)。

极限运算法则适用于相关极限存在且运算有意义的情形。夹逼定理、单调有界定理、数列收敛准则是证明极限存在的重要工具。

## 3. 两个重要极限与常用等价无穷小

\[
\lim_{x\to0}\frac{\sin x}{x}=1,\qquad
\lim_{x\to\infty}\left(1+\frac1x\right)^x=e.
\]

当 (x\to0)：
\[
\sin x\sim x,\quad \tan x\sim x,\quad
1-\cos x\sim\frac{x^2}{2},
\]
\[
\ln(1+x)\sim x,\quad e^x-1\sim x,\quad
a^x-1\sim x\ln a,
\]
\[
(1+x)^\alpha-1\sim\alpha x.
\]

等价无穷小可用于乘除因子替换；在加减结构中不能随意把某一项替换为等价项，必须先判断主导项或整体等价关系。

## 4. 未定式与求极限策略

常见未定式：(0/0,\infty/\infty,0\cdot\infty,\infty-\infty,1^\infty,0^0,\infty^0)。

建议顺序：
1. 代入判断类型；
2. 因式分解、约分、有理化；
3. 提取最高阶、通分或变量代换；
4. 使用等价无穷小或重要极限；
5. 满足条件时使用洛必达法则；
6. 幂指型可取对数，先求指数极限。

洛必达只适用于可化为 (0/0) 或 (\infty/\infty) 且满足相应可导、分母导数非零等条件的情形。不能把它当作任意分式的机械求导法。

## 5. 连续与间断

(f) 在 (x_0) 连续当且仅当：
- (f(x_0)) 有定义；
- \(\lim_{x\to x_0}f(x)\) 存在；
- 极限等于函数值。

间断点分类：
- 可去间断：左右极限相等且有限，但函数值未定义或不等于极限；
- 跳跃间断：左右极限有限但不相等；
- 无穷间断：至少一侧趋于无穷；
- 振荡间断：极限因振荡不存在。

闭区间连续函数的重要结论：有界性与最值定理、介值定理、零点定理。使用时必须同时满足闭区间与连续性等前提。

## 6. 典型题型模板

**参数求极限**：先列左右极限或整体极限存在条件，再比较主导项，最后解参数；不要只比较一侧。

**分段函数连续性**：在分段点分别求左极限、右极限和函数值，三者相等才连续。

**数列极限证明**：从目标不等式反推 (N(\varepsilon))，最后验证任意 (n>N) 均成立。

**极限存在性**：优先寻找单调有界、夹逼、柯西准则或左右极限相等的证据。

## 7. 易错点与自测

- 把“函数有定义”误认为“函数连续”。
- 在加减式中不加条件地替换等价无穷小。
- 洛必达后仍是未定式时没有继续判断，或对非未定式使用。
- 忽略左右极限，尤其是分段函数和绝对值。
- 忘记无穷远处极限与趋于有限点的定义不同。

自测：
1. 说明连续与可导的逻辑关系，并给出反例说明连续不必可导。
2. 求 (\lim_{x\to0}(e^x-1-x)/x^2)。
3. 讨论分段函数在连接点连续所需的参数条件。
4. 解释为什么 (a_n\to0) 不能推出 \(\sum a_n\) 收敛。
