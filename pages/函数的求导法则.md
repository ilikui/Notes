# 函数的求导法则

> 求导法则把复杂函数的导数转化为已知函数导数的组合。使用时先确认函数在相关区间可导，并注意商法则的分母不能为零、复合函数需要使用链式法则。

## 1. 基本法则

设 u = u(x)、v = v(x)，且它们在讨论点可导：

| 运算 | 求导法则 | 条件/提示 |
|---|---|---|
| 常数 | (C)' = 0 | C 为常数 |
| 常数倍 | (Cu)' = C u' | C 为常数 |
| 和与差 | (u ± v)' = u' ± v' | 两函数均可导 |
| 乘积 | (uv)' = u'v + uv' | 不能只对其中一项求导 |
| 商 | (u/v)' = (u'v - uv') / v² | v ≠ 0 |
| 复合函数 | (f(g(x)))' = f'(g(x)) · g'(x) | 链式法则 |
| 反函数 | (f⁻¹)'(y) = 1 / f'(x)，其中 y=f(x) | 需满足局部可逆及相应可导条件，且 f'(x) ≠ 0 |

## 2. 例子

### 和与差

若 y = x² + 3x，则 y' = 2x + 3。

### 乘积

若 y = x² sin(x)，则：

y' = 2x sin(x) + x² cos(x)。

### 商

若 y = (x + 1) / x，且 x ≠ 0，则：

y' = [x - (x + 1)] / x² = -1 / x²。

### 复合函数

若 y = (3x + 1)²，则外层函数为平方函数，内层函数为 3x + 1：

y' = 2(3x + 1) · 3 = 18x + 6。

## 3. 常见错误

- 把乘积的导数误写为 u'v'。
- 忘记商法则分母是 v²。
- 对复合函数求导时忘记乘以内层函数的导数。
- 使用反函数求导公式时，忽略可逆性或导数非零条件。
- 忽略定义域，导致在不可导点或分母为零处套用公式。

## 4. 推荐练习步骤

1. 先标出函数的组成部分与运算类型。
2. 判断需要使用哪条法则；复合运算可能需要多条法则。
3. 分步求导，最后再化简。
4. 用数值代入或图像趋势做合理性检查，但不要用数值检查替代证明。
5. 对结果求导或积分回代时，注意积分常数和定义域条件。
