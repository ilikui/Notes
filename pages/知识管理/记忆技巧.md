# 记忆技巧：回忆、间隔与意义

- 联想记忆
- 重要记忆

记忆不是把信息反复看熟，而是建立可提取的线索，并在适当间隔后主动尝试回忆。

## 推荐方法

- **主动回忆**：合上资料，先写出自己记得的内容，再对照修正。
- **间隔复习**：把复习分散到多个时间点，而不是集中在一次长时间重复。
- **精细加工**：解释原因、比较相似概念、自己造例子。
- **双重编码**：在适合的内容中结合语言与图示。
- **联想与故事**：对难记的序列、术语或顺序建立有意义的线索。
- **混合练习**：交替练习相近题型，训练区分与选择策略。

## 复习闭环

```mermaid
flowchart LR
    A[学习新内容] --> B[合上资料回忆]
    B --> C[核对并纠错]
    C --> D[安排下次复习]
    D --> E[在新问题中应用]
    E --> B
```

## 设计一张复习卡

一个问题聚焦一个关键知识点，答案应能验证是否理解，并避免过多无关信息。技术卡片可以问“为什么这样配置”“故障时先检查什么”“什么条件下结论不成立”，而不只是问缩写全称。

复习计划的目标是帮助长期提取与应用。若已经能够稳定解释并在项目中使用，可以减少机械复习，把时间转向更高阶的问题。
