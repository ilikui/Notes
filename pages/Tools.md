# 汽车嵌入式开发工具地图

工具应服务于开发、配置、构建、调试、测量和验证流程。选型时需要确认工具版本、许可证、目标芯片支持、团队流程和生成工件的可复现性。

- [[Configuration Tools]]：系统建模、ARXML 配置、代码生成与一致性检查
- [[Development Tools]]：IDE、编译器、链接器、静态分析与版本控制
- [[Testing Tools]]：单元测试、集成测试、覆盖率与自动化测试
- [[Monitoring Tools]]：调试器、总线分析、日志、示波器与逻辑分析仪
- [[Trace 32]]：底层调试和处理器状态分析
- [[Git]]：版本控制与代码审查

## 工具链关系

```mermaid
flowchart LR
    A[需求/模型] --> B[配置工具]
    B --> C[生成代码]
    C --> D[编译器/链接器]
    D --> E[固件/目标文件]
    E --> F[下载与调试]
    F --> G[测试/总线测量/日志]
    G --> H[缺陷记录与回归]
    H --> A
```

## 工具使用的工程规范

1. 记录工具名称、版本、插件、配置和关键命令行参数。
2. 保存构建日志、链接映射、测试报告和必要的测量数据。
3. 自动生成工件应能从明确的输入基线重建。
4. 对工具升级做兼容性评估，重点关注生成代码差异和结果变化。
5. 将手工步骤转为脚本或检查清单，但在自动化后仍保留失败诊断信息。
