# 开发者基础工具

- [[VIM]]：终端文本编辑器与高效文本操作。
- [[Emacs]]：可扩展的文本编辑与工作环境。
- [[Git]]：版本控制、分支管理和协作。

## 建议掌握的最低能力

### 编辑器
- 快速移动、搜索、替换和多文件编辑。
- 理解配置文件、插件和快捷键映射。
- 能在终端环境下完成必要的编辑工作。

### Git
- 查看状态和差异。
- 创建分支、提交、合并和解决冲突。
- 与远程仓库同步并通过 Pull Request 审查修改。

### 通用命令行
- 文件与目录操作、文本检索、管道和重定向。
- 运行脚本并读取退出码与日志。
- 管理环境变量、路径和工具版本。

不需要一开始记住所有命令。优先练熟高频工作流，再按任务扩展。
