# 笔记系统的用户体验

- 界面简洁
- 易用性
- 定制化
- 跨平台同步
- 快捷操作

## 核心体验指标

| 体验目标 | 可观察问题 |
|---|---|
| 低摩擦记录 | 能否快速捕捉想法，不打断当前任务？ |
| 易于检索 | 能否用标题、全文搜索或链接找到内容？ |
| 理解成本低 | 页面是否有清晰标题、层级、示例和图示？ |
| 跨设备连续性 | 同步失败或离线编辑时是否有清楚反馈？ |
| 可控与可信 | 数据是否可导出、备份和恢复？ |
| 可访问性 | 键盘操作、字号、对比度和链接是否易用？ |

## 体验改进流程

观察真实使用，识别摩擦点，提出改进假设，小范围试验，比较前后效果，再决定保留、调整或撤回。

不要仅凭视觉偏好判断体验好坏。优先解决影响任务完成率、检索速度、错误恢复和长期维护的问题。
