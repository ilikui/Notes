## 选择工具时的比较维度

| 维度 | 需要确认 |
|---|---|
| 数据所有权 | 数据保存在本地、云端还是两者兼有？ |
| 导出与迁移 | 是否支持 Markdown、HTML、PDF 或其他开放格式？ |
| 组织方式 | 文件夹、标签、大纲、双向链接、数据库视图是否满足需求？ |
| 搜索 | 是否支持全文检索、过滤和跨页面链接？ |
| 同步与离线 | 离线时能否编辑，冲突如何处理？ |
| 扩展能力 | 是否有插件、API、自动化和备份方案？ |
| 隐私 | 是否适合存储工作资料、个人数据和敏感信息？ |

迁移前先导出少量样本，检查中文、图片、附件、链接、代码块和日期是否完整；确认流程可重复，再迁移全部数据。迁移前保留原始备份，不要把导入成功等同于内容完整。
