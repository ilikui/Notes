# 嵌入式硬件基础

嵌入式硬件是运行嵌入式软件的物理基础，包含处理器、存储器、电源、时钟、复位、外设、传感器、执行器和通信接口。硬件设计与软件配置必须协同验证。

## 主要组成

- **处理器/MCU/SoC**：执行程序，提供定时器、ADC、PWM、通信控制器等资源。
- **存储器**：Flash/ROM 保存程序，RAM 保存运行时数据，EEPROM 或 Flash 区域可保存持久化数据。
- **电源与时钟**：决定上电时序、功耗、频率和系统稳定性。
- **输入输出**：GPIO、ADC、DAC、PWM、捕获比较等。
- **通信接口**：[[CAN]]、[[LIN]]、SPI、UART、I²C、Ethernet 等。
- **传感器与执行器**：把物理量转换为电信号，或把控制命令转为物理动作。

## 开发板与学习平台

- Arduino：适合快速验证基础 I/O 和原型。
- Raspberry Pi：适合运行较完整操作系统与高层应用。
- BeagleBone：适合 Linux 与硬件接口实验。
- 专用 MCU 开发板：适合学习实时控制、寄存器、驱动和车规相关工具链。

不同平台的运行模型和实时能力不同，选择时应依据学习目标。

## 硬件排查顺序

1. 检查电源、接地、复位和时钟。
2. 核对芯片型号、引脚复用和电气规格。
3. 用万用表、示波器或逻辑分析仪测量实际信号。
4. 检查驱动配置、时序和外设状态寄存器。
5. 对照原理图、数据手册和软件日志验证假设。
