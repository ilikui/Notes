# 软件与工具学习

软件学习的目标是把工具融入真实工作流，而不是收集功能列表。

- [[LogSeq]]：组织 Markdown 页面、日记和双向链接。
- [[SuperMemo]]：间隔复习与记忆训练入口。
- [[Git]]：版本控制与协作。
- [[学习工具]]：根据任务选择合适工具。

## 学习一款软件的步骤

1. 明确它解决的问题，以及不适合解决的问题。
2. 从官方文档学习最小工作流。
3. 用真实任务练习，而不是只浏览所有设置。
4. 记录快捷键、关键概念和常见故障。
5. 评估数据导出、备份、恢复和迁移方式。
6. 定期检查工具是否仍适合当前工作流。

## 一周试用评估

选一个真实任务，记录使用前后的完成时间、错误数量、检索成本和维护工作量。若工具没有改善结果，或引入了更高的维护成本，就简化配置、换工具或停止使用。
