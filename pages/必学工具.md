# 开发者基础工具

开发者应能使用编辑器、版本控制和命令行完成日常工作。掌握高频工作流比记住大量命令更重要。

- [[VIM]]：终端文本编辑器与高效文本操作。
- [[Emacs]]：可扩展的文本编辑与工作环境。
- [[Git]]：版本控制、分支管理和协作。

## 最低能力清单

### 编辑器
- 快速移动、搜索、替换和多文件编辑。
- 使用分屏、撤销/重做和多光标或批量编辑能力。
- 理解配置文件、插件和快捷键映射。

### Git
- 查看状态与差异，理解暂存区和提交。
- 创建分支、提交、合并并解决冲突。
- 同步远程仓库，通过 Pull Request 进行审查。
- 出现问题时能查看历史并恢复误操作。

### 命令行
- 文件与目录操作、文本检索、管道和重定向。
- 运行脚本并检查退出码和日志。
- 管理环境变量、路径和工具版本。

## 练习项目

在一个小型 Markdown 或代码仓库中完成：新建分支、编辑文件、查看 diff、提交、合并并回滚一次测试提交。先在可丢弃的练习仓库操作，再应用到重要项目。
